基于低信息泄露协商算法的无线信道密钥生成方案

无线通道密钥生成难题

  1. 动态环境下的密钥稳定性：
    • 无线环境是动态变化的，如何在频繁变化的信道条件下保持密钥的稳定性和安全性是一个挑战
  2. 抗干扰和抗攻击：
    • 无线环境中存在各种干扰和潜在的攻击，如何确保密钥生成过程不受这些因素的影响是一个难题
  3. 密钥分发的安全性：
    • 在无线环境中，密钥的分发可能更容易受到攻击，如何确保密钥在分发过程中的安全性是一个重要问题
  4. 实时性和效率：
    • 无线通道密钥生成需要满足实时性要求，同时还要保证生成过程的高效性，这需要在算法设计和实现上进行权衡

系统模型

Alice和Bob是合法通信用户，Eve是窃听者。系统采用时分双工（TDD）方式工作

Alice 和 Bob 会互相发送导频信号对信道进行探测，将信道特征量化得到初始密钥，经信息协商得到一对对称的密钥,最后进行隐私放大以提高密钥的随机性

密钥生成示意图

信道探测和预处理

为了获取信道的特征信息

  1. Alice和Bob互相发送包含PN序列的导频信号
  2. 计算接收信号与PN序列的互相关结果，找到相关峰
    • 利用 PN 序列相关结果的对称性计算采样时刻与最佳 采样时刻之间的延时
  3. 利用相关峰及其前后各3个采样点计算重心，得到延时
  4. 对信号进行内插，调整采样时刻，使其处于最佳采样时刻

通过预处理，可以有效提升信道特征的互易性，从而降低初始密钥的不一致率，为后续的信息协商过程减少信息泄露，提高密钥的安全性

量化

将信道探测得到的连续信道特征转换为离散的比特序列，即初始密钥

本文介绍了两种带保护间隔的量化方法：单比特量化和基于累积分布函数（CDF）的两比特量化

单比特量化：将信道特征的采样点分为两个区间，并在两个区间之间设置一个保护间隔，保护间隔内的采样点将被去除

基于CDF的两比特量化：在数据CDF的25%、50%和75%处设置三个保护间隔，然后通过插值算出保护间隔在数据中的范围

信息协商

允许两个合法用户（例如Alice和Bob）在有潜在窃听者（例如Eve）的情况下，协商并生成一个共享的秘密密钥。在论文中，作者专注于解决信息协商过程中的信息泄露问题，并提出了一种改进的Cascade算法，称为低信息泄露Cascade算法

传统Cascade算法

Cascade算法是一种广泛使用的信息协商方法，包括主算法和子算法（BINARY算法）

  1. 在主算法中，Alice将序列分块并计算奇偶校验码，然后发送给Bob。Bob接收到校验码后与自己的结果进行对比
  2. 如果不同则使用子算法纠错。BINARY算法通过二分查找错误比特，直到找到错误的比特位置

信息泄露问题：在协商过程中，通过交换校验码会导致信息泄露给窃听者。

在BINARY算法的最后一步，子块大小等于1，意味着校验码就是密钥本身，直接泄露了1比特密钥

论文中分析了Cascade算法中的信息泄露问题，并指出校验码之间的冗余意味着泄露的信息量实际上小于发送的校验码总数

低信息泄漏的Cascade算法

改进BINARY算法

  • 停止递归：在序列长为2或3时停止递归，避免直接泄露密钥
  • 删除不一致比特：删除不一致比特，减少信息泄露

改进后的 BINARY 算法不会直 接泄露密钥本身

改进的 BINARY 算法删除了密钥中的一部分，从窃听方的角度来看相当于方程组中的部分未知数需要删除

块长变化

块长越小,则块数越多,信息泄露更多;相对地，算法的纠错能力也更强。 轮数越多泄露的信息也更多,但是协商的 成功率也越高

低信息泄露 Cascade 算法在主算法中加入了块长变化的步骤

在算法的某一轮开始时将块长增大。 在协商初期使用小块长快速降低比特不一致率(BDR) 后续的步骤中使用大块长减少信息泄露

分类交织

删除不一致比特, 这将导致它在每一轮协商中分块的结构不同

需要将密钥分为两类进行交织，减少信息泄露

  1. 将密钥分为两类：A类（上一轮处于不一致块中被保留的部分）和B类（其余部分）
  2. B类中先取除尽块长平方的最大长度的一部分进行交织
  3. B类中剩余的部分和A类一起进行交织
  4. 将两部分组合起来得到新的序列

长游程问题

截断游程：截断游程超过4的部分，每部分只保留4个比特，降低游程，提高密钥随机性

长游程问题来源于信道特征。 CIR 信道冲激响应 幅值最大值 虽然有着很好的互易性,但是它不太可能始终保持 着剧烈的抖动,这导致了在初始密钥中出现长连 0、 1 的情况,密钥存在长游程问题。

  1. Cascade 代表传统算法,
  2. Low leak 代表低信息泄露算法
  3. Light 代表轻量级算法
  4. Interleaving 代表使用交织的低信息泄露算法
  • 低信息泄露算法在较低BDR时与传统算法的成功率相同，在较高BDR的情况下成功率不如传统算法
