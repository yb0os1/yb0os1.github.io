sev-step-meta

这个元仓库（meta repo）会跟踪所有 SEV STEP 组件的兼容状态，并包含用于安装设置 SEV 虚拟机所需一切组件的脚本。

本手册已在运行 Ubuntu 22.04.2 LTS 的戴尔 PowerEdge R6515 服务器（配备 AMD EPYC 7763 CPU）上进行了测试。

此仓库使用了 Git 子模块。运行 git submodule update --init --recursive 来获取所有子模块。

构建管理程序组件

在本部分，你将安装经过修改的 SEV STEP 内核，以及兼容版本的 QEMU 和 OVMF/edk2。此仓库的制品（artifact）部分有内核的预构建 .deb 文件。这些文件是基于 Ubuntu 22.04.2 LTS 的配置构建的。如果你在使用预构建的二进制文件时遇到任何问题，也可以根据你当前的活动配置自行构建内核（见步骤 2）。

  1. 运行 ./build.sh ovmf、./build.sh qemu 来构建 OVMF 和 QEMU。如果你遇到任何缺失的依赖项，可以尝试运行 sudo apt-get build-dep ovmf qemu-system-x86。所有软件包仅会本地安装到 ./local-installation/ 目录下。
  2. 如果你不使用预构建的内核软件包，运行 ./build.sh kernel 以根据当前活动内核的配置来构建内核。之后，使用 dpkg -i ./kernel-packages/*.deb 安装这些软件包。

创建并运行 SEV 虚拟机

在本部分，我们将使用刚刚构建的工具链来设置一个 SEV SNP 虚拟机。

  1. 使用 ./local-installation/usr/local/bin/qemu-img create -f qcow2 <VM_DISK.qcow2> 20G 为虚拟机创建一个磁盘。
  2. 使用 sudo ./launch-qemu.sh -hda <VM_DISK.qcow2> -cdrom <Ubuntu 22.10 iso> -vnc :1 启动虚拟机，其中 <Ubuntu 22.10 iso> 是常规 Ubuntu 安装镜像的路径。虽然你可以使用其他发行版，但它们对 SEV 的支持可能有所不同。最重要的是，它们至少要搭载内核版本 5.19，因为这是第一个支持作为 SEV SNP 客户机运行的主线内核版本。
  3. 通过 VNC 查看器连接到虚拟机的 5901 端口，并进行标准安装。
  4. 安装完成后，使用 ctrl a+x 终止 QEMU 进程，或者使用 sudo kill $(pidof qemu-system-x86)。
  5. 再次启动虚拟机并使用 VNC 连接。安装 OpenSSH 服务器并将其配置为自动启动。./launch-qemu.sh 脚本已经将虚拟机的 22 端口转发到主机的 2222 端口，将虚拟机的 8080 端口转发到主机的 8080 端口。
  6. 使用 sudo ./launch-qemu.sh -hda <VM_DISK.qcow2> -sev-snp 以 SEV - SNP 保护模式启动虚拟机。你可能还需要提供 -allow-debug 参数，该参数启用 SEV 调试 API。SEV STEP 框架的许多测试功能需要此参数才能访问虚拟机的指令指针或其他寄存器内容。

解析

这份文档是关于 SEV（Secure Encrypted Virtualization，安全加密虚拟化） STEP（Simplified Trusted Execution and Protection，简化的可信执行与保护）相关组件的使用说明和操作指南。主要包括以下几个部分：

  1. 仓库介绍：说明该元仓库的用途是跟踪 SEV STEP 组件的兼容状态，并包含安装脚本，同时指出使用了 Git 子模块。
  2. 构建管理程序组件：详细介绍了构建 SEV STEP 内核、QEMU 和 OVMF/edk2 的步骤，包括使用预构建文件或自行构建的方法，还给出了内核配置文件的内容和启动新内核的信息，以及启用 SEV 所需的 BIOS 选项和验证 SEV 是否启用的命令及预期输出。
  3. 创建并运行 SEV 虚拟机：提供了创建和运行 SEV SNP 虚拟机的详细步骤，包括创建磁盘、启动虚拟机、安装操作系统、配置 SSH 服务器等，还提到了使用 SEV - SNP 保护模式启动虚拟机的方法和调试参数。
  4. 使用 Sev Step 库：引导用户查看 sev-step-userland 子模块中的 README.md 文件以了解如何使用该库。
  5. 参考文献：列出了参考的链接。
