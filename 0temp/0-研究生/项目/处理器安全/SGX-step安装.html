需要的Linux 内核参数

Linux 内核参数 目的
nox2apic 可选配置本地 APIC 设备为内存映射 I/O 模式（以利用 SGX-Step 的精确单步执行特性）。若设置此参数，需确保在 libsgxstep/config.h 中将 X2APIC 设为 0。也可让 CPU 保持 x2APIC 模式，近期的 SGX-Step 发行版同样兼容。
iomem=relaxed no_timer_check 抑制内核日志中不必要的警告信息。
nmi_watchdog=0 禁用内核 NMI 看门狗（NMI watchdog）。
isolcpus=1 将受害进程固定到一个隔离的 CPU 核心。
clearcpuide=308,295,514 禁用监管模式访问防护（SMAP，295 位）、监管模式执行防护（SMEP，308 位）和用户模式指令防护（UMIP，514 位）特性
pti=off 禁用内核页表隔离（以避免用户 IRQ 处理程序引发内核崩溃）。
rcupdate.rcu_cpu_stall_suppress=1 禁用内核的写时复制更新（RCU）CPU 停滞检测器（避免长时间单步执行且不调用内核定时器中断处理程序时产生警告）。
msr.allow_writes=on 抑制 SGX-Step 对特定模型寄存器（MSR）写入操作的内核警告信息
vdso=0 仅适用于新版 Linux 内核：禁用 vdso_sgx_enter_enclave 库（与 AEP 拦截补丁不兼容）
dis_ucode_ldr 可选禁用 CPU 微码更新（近期瞬态执行攻击缓解措施可能需要重新校准单步执行间隔）

报错

  1. vm_flags 只读限制

    • 内核 5.15+ 引入 vma->vm_flags 只读保护，需通过 vm_flags_set() 修改。

  2. get_unmapped_area 接口变更

    • 内核 5.10+ 移除 struct mm_struct->get_unmapped_area，改用 mmap 相关函数。

    • addr = current->mm->get_unmapped_area(file, addr, 2 * len, pgoff,
					      flags);

addr = file->f_op->get_unmapped_area(file, addr, 2 * len, pgoff,
					      flags);

  3. 函数指针类型不匹配

    • sgx_drv_remove 返回 int，而内核要求 void (*)(struct platform_device *)。 修改int
