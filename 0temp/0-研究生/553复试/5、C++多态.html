设计一个电影类 Movie，用于管理影视库中的电影信息，具体要求如下：

  • 包含三个私有成员：电影名称（std::string 类型）、上映年份（int 类型）、评分（double 类型，范围 0 - 10）
  • 编写默认构造函数，将电影名称初始化为 "Unknown"，上映年份初始化为 0，评分初始化为 0.0。编写带有三个参数（电影名称、上映年份、评分）的构造函数
  • 重写输出 << 运算符，设置输出格式为 Movie Name: [电影名称], Release Year: [上映年份], Rating: [评分] 这种形式
  • 重写比较 < 运算符，按照评分从低到高进行比较，如果评分相同，则按照上映年份从早到晚进行比较
  • 写一个判断函数，判断当前电影信息是否合法（上映年份需大于等于 1895，因为电影诞生于 1895 年；评分需在 0 - 10 范围内），如果不合法把电影信息设置成一个固定的默认信息（电影名称："Invalid Movie"，上映年份：1895，评分：0.0）
  • 重写乘法 * 运算符，实现对电影评分进行加权操作。输入一个 double 类型的权重值，将当前电影评分乘以该权重值，同时要确保新的评分仍在 0 - 10 范围内。若超出范围，将评分调整为最接近的边界值（0 或 10）
  • 写一个筛选函数，从电影数组中筛选出评分高于指定阈值的电影，并将这些电影存储在一个新的数组中返回
  • 写一个排序函数，将筛选后的电影数组按照 < 运算符的比较规则进行从小到大排序
