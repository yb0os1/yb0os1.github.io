选择题

1、D。非const对象可以调用const成员函数，只是const对象只能调用const成员函数，以保证对象的常量性不被破坏 。

2、C。引用必须在定义时初始化，且初始化后不能再引用其他变量；不存在引用的数组，因为引用不是一个独立的变量，没有自己的存储空间。引用本质上是一个指针常量，即一旦绑定，就不能再改变指向。

3、D。多态分为编译时多态和运行时多态，函数重载和模板是编译时多态的实现方式，运行时多态通过虚函数实现，但虚函数必须在派生类中重写，通过基类指针或引用调用时才能体现运行时多态。

4、C

  • A:静态局部变量是在函数内部使用static关键字声明的变量。普通局部变量在函数调用结束后会被销毁，而静态局部变量在程序的整个生命周期内都存在，只会在第一次调用函数时进行初始化，之后再次调用该函数时，静态局部变量会保留上一次调用结束时的值

  • B:静态成员变量属于类本身，而不是类的某个对象，所有对象共享同一个静态成员变量。类的定义只是对类的一种声明，并不会为静态成员变量分配实际的内存空间。因此，需要在类外进行定义和初始化，以分配内存。

  • C:静态成员函数属于类本身，而不是类的某个对象，它不依赖于特定的对象实例。静态成员函数只能访问类的静态成员变量和静态成员函数，不能访问类的非静态成员变量和非静态成员函数，因为非静态成员变量和非静态成员函数是与对象相关的，而静态成员函数没有 this 指针，无法确定要访问哪个对象的非静态成员。

  • D:this 指针是一个隐含的指针，它指向调用成员函数的对象。静态成员函数属于类本身，不依赖于特定的对象实例，因此没有 this 指针

5、C

  • A. 模板分为函数模板和类模板：在 C++ 里，模板是一种通用编程工具。函数模板可以用来创建通用函数，让函数能够处理不同数据类型，如template <typename T> T add(T a, T b) { return a + b; } ，能对不同类型（如int、double等）进行加法操作。类模板用于创建通用类，像template <typename T> class Stack { /*... */ }; ，可生成针对不同数据类型的栈类。所以 A 选项正确。
  • B. 模板的实例化分为隐式实例化和显式实例化：隐式实例化是指当编译器遇到模板的具体使用时，自动根据实际参数类型生成相应的实例，例如使用前面的add函数模板时，int result = add(1, 2); ，编译器会自动实例化出add<int>版本。显式实例化则是程序员明确指定要实例化的模板版本，如template int add<int>(int, int); 。因此 B 选项正确。
  • C. 模板特化时，模板参数列表必须完全指定：模板特化分为全特化和偏特化。全特化时，模板参数列表必须完全指定，例如template <> class Stack<int> { /*... */ }; 。但偏特化时，只需部分指定模板参数，像template <typename T> class Stack<T*> { /*... */ }; ，这里只对指针类型进行了部分特化。所以 C 选项错误。
  • D. 函数模板可以被重载：函数模板和普通函数一样可以被重载，只要函数模板的参数列表不同就行。比如有函数模板template <typename T> T add(T a, T b) { return a + b; } ，还能定义template <typename T> T add(T a, T b, T c) { return a + b + c; } ，这两个函数模板因参数列表不同而构成重载关系。所以 D 选项正确 。

6、B。由于A的析构函数不是虚函数，当通过A类型的指针删除B对象时，只会调用A的析构函数，而不会调用B的析构函数，这可能会导致内存泄漏或资源未正确释放。如果将A的析构函数声明为虚函数，就会先调用B的析构函数，再调用A的析构函数。

7、B

  • 当使用#include <filename>时，编译器会在系统标准路径中查找文件。系统标准路径通常是编译器和系统预先设定好的，存放系统自带头文件的目录。像<iostream>、<cmath>这类标准库头文件，就适合用这种方式包含，因为它们都在系统标准路径下。
  • 当使用#include "filename"时，编译器首先会在当前源文件所在的目录查找文件。如果在当前目录没找到，才会到系统标准路径查找。对于用户自定义的头文件，一般都放在当前项目的源文件目录下，所以使用这种方式包含更合适，这样能优先从项目内部查找，避免与系统标准路径下同名文件冲突。

\a：这是一个转义字符，表示警报（响铃）符，在字符串中占 1 个字符位置。\b：同样是转义字符，代表退格符，占 1 个字符位置。\t：水平制表符，占 1 个字符位置。\y：在 C++ 里，这并非有效的转义字符。当 \ 后面跟着未定义的字符时，\ 会被忽略，所以 \y 实际上就是字符 y，占 1 个字符位置。\xc：这是十六进制转义序列，代表一个字符，其十六进制值为 0xc（也就是十进制的 12），占 1 个字符位置。\\：转义字符，表示反斜杠字符 \，占 1 个字符位置。0：普通字符 0，占 1 个字符位置。第一个 \0：字符串结束符，strlen 函数遇到它就会停止计数。

简答题

多继承的优缺点

  • 优点：多重继承使 C++ 的类能够从多个基类中继承属性和行为，实现更灵活的代码复用，能更自然地模拟现实世界中复杂的关系。
  • 缺点：可能导致代码复杂度增加，出现命名冲突、二义性问题，最典型的就是菱形继承问题，使得代码的可读性、维护性变差。

避免潜在问题的方法

  • 使用虚继承：在菱形继承结构中，通过虚继承可以确保从多个路径继承而来的公共基类只被实例化一次，解决数据冗余和二义性问题。
  • 合理设计类层次结构：在设计时要深入分析类之间的关系，确保多重继承的结构清晰合理，避免无意义或复杂混乱的继承关系。
  • 遵循命名规范：为类和成员命名时遵循统一规范，减少命名冲突的可能性。
